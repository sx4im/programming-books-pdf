## For Beginners

These books are perfect if you are new to Haskell or functional programming.

- **Learn You a Haskell for Great Good!** (*1st Edition*)
- **Haskell Programming from First Principles** (*1st Edition*)
- **Get Programming with Haskell** (*1st Edition*)

## For Intermediate Developers

Once you know the basics, these books help you write idiomatic, type-driven Haskell.

- **Programming in Haskell** (*2nd Edition*)
- **Haskell in Depth** (*1st Edition*)
- **Real World Haskell** (*1st Edition*)

## For Advanced Programmers

Deep dives into type systems, concurrency, and advanced abstractions.

- **Parallel and Concurrent Programming in Haskell** (*1st Edition*)
- **Thinking with Types** (*1st Edition*)

## For Specialized Fields

Focus on parsers, compilers, and production functional systems.

- **Pearls of Functional Algorithm Design** (*1st Edition*)
- **Functional Design and Architecture** (*1st Edition*)
