## For Beginners

These books introduce Julia's syntax and its appeal for high-performance scientific and numerical computing.

- **Think Julia: How to Think Like a Computer Scientist** (*1st Edition*)
- **Introducing Julia** (*Online Resource*)
- **Julia Programming for Operations Research** (*2nd Edition*)
- **Julia 1.0 By Example** (*1st Edition*)

## For Intermediate Developers

Once you know the basics, these books help you write efficient, idiomatic Julia for science and engineering.

- **Julia High Performance** (*2nd Edition*)
- **Learning Scientific Programming with Julia** (*1st Edition*)
- **Julia Data Science** (*Free online book*)

## For Advanced Programmers

Dive deep into Julia's type system, multiple dispatch, metaprogramming, and performance tuning.

- **Algorithms for Optimization** (*1st Edition*)
- **Algorithms for Decision Making** (*1st Edition*)
- **Julia 1.7 Cookbook** (*1st Edition*)

## For Specialized Fields

Focus on applying Julia to data analysis, statistics, and machine learning.

- **Statistics with Julia** (*1st Edition*)
- **Machine Learning with Julia** (*1st Edition*)
- **Quantitative Economics with Julia** (*Online Resource*)
