## For Beginners

These books introduce Elixir's functional style and the actor-based concurrency model that runs on the battle-tested Erlang VM.

- **Elixir Getting Started Guide** (*Official free guide*)
- **Elixir School** (*Online Resource*)
- **Programming Elixir 1.6** (*1.6 Edition*)
- **Learn Functional Programming with Elixir** (*1st Edition*)
- **Introducing Elixir** (*2nd Edition*)

## For Intermediate Developers

Once you know the basics, these books help you build real applications with OTP, processes, and tooling.

- **Elixir in Action** (*2nd Edition*)
- **Craft GraphQL APIs in Elixir with Absinthe** (*1st Edition*)
- **Adopting Elixir** (*1st Edition*)

## For Advanced Programmers

Deep dives into metaprogramming, OTP design, and production-grade Elixir systems.

- **Metaprogramming Elixir** (*1st Edition*)
- **Designing Elixir Systems with OTP** (*1st Edition*)
- **Property-Based Testing with PropEr, Erlang, and Elixir** (*1st Edition*)

## For Specialized Fields

Focus on Phoenix, Ecto, LiveView, and real-time web systems.

- **Programming Phoenix 1.4** (*1.4 Edition*)
- **Programming Ecto** (*1st Edition*)
- **Programming Phoenix LiveView** (*1st Edition*)
